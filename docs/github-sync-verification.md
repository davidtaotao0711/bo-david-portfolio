# GitHub 同步验收

日期：2026-09-07。来源：`davidtaotao0711/bo-photography`，用户明确授权只读导入。

## 实现与边界

- 本地编辑器提供「从 GitHub 同步」按钮、下载说明、图片处理进度与错误反馈。
- 本机 Git 凭据读取固定仓库；部分克隆只下载所需数据和图片，不执行来源仓库代码，不修改远端。
- 采用固定提交的树与数据，分批读取图片对象；Git 对象获取使用 `fetch.negotiationAlgorithm=noop`，避免部分克隆进行普通提交协商时的对象检查错误。
- 图片在本项目保存，生成 320 / 640 / 960 / 1440 / 2000 的 AVIF、WebP、JPEG；相同原图内容复用文件。
- 两个图片处理任务并行；全部完成后发布项目数据。已有项目、顺序、封面、项目文字和远端已删除的照片均保留。
- 编辑器不包含 Vite 刷新客户端，批量处理中不会因新文件导致整个编辑页面自动刷新。
